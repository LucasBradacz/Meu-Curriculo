# Meu Currículo — Webapp Interativo

Projeto da Unidade I (Webapps): página estática interativa com HTML5, CSS3 e JavaScript.

## Estrutura
```
/curriculo/
├── index.html
├── style.css
├── script.js
├── README.md
└── /media/
    ├── lucas.jpg 
```


## Funcionalidades JavaScript incluídas
- Alerta de boas-vindas ao clicar em um botão.
- Mostrar/esconder uma seção de detalhes (`addEventListener` + `classList.toggle`).
- Formulário que captura o nome digitado e atualiza o `innerText` do título
  e de uma mensagem de saudação personalizada.
- Botão que alterna a cor de fundo da página.
- Contador de visitas persistente usando `localStorage`.
- Ano atual exibido automaticamente no rodapé.
